# FormulaSAE-Aero-Validation

CFD and wind tunnel aerodynamic validation project developed for a Formula SAE electric vehicle.

---

# Overview

This project combines Computational Fluid Dynamics (CFD), wind tunnel testing, instrumentation, data acquisition, and signal post-processing for aerodynamic validation and development of a Formula SAE aerodynamic package.

The workflow integrates:

- Aerodynamic CAD automation
- CFD aerodynamic analysis
- Wind tunnel experimental testing
- Instrumentation and data acquisition
- Signal filtering and post-processing
- Numerical–experimental correlation

---

# Main Areas

## CAD Automation
Python and VBS automation workflows developed for CATIA V5 aerodynamic geometry generation.

## Wind Tunnel DAQ
Arduino-based aerodynamic force-balance acquisition system using HX711 modules and Python-based data logging.

## Post-Processing
MATLAB-based aerodynamic signal filtering, statistical analysis, and aerodynamic force visualization.
