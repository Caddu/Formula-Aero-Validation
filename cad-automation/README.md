# CAD Automation

This directory contains CATIA V5 aerodynamic geometry automation workflows developed using Python and VBS scripting.

The automation framework was created to accelerate aerodynamic component generation and support CFD-driven aerodynamic development iterations for Formula SAE applications.

The workflow enables rapid aerodynamic geometry generation and supports iterative aerodynamic optimization processes.
