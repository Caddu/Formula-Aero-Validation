# Post Processing

This directory contains MATLAB-based aerodynamic signal-processing workflows developed for wind tunnel aerodynamic force-balance analysis.

The workflow performs filtering, outlier rejection, offset correction, statistical analysis, and aerodynamic force visualization for experimental aerodynamic validation.

The post-processing methodology was developed specifically for 1:8 scale aerodynamic testing and numerical–experimental correlation studies.

---

# Main Features

- CSV parsing
- Decimal separator correction
- Moving-median outlier rejection
- Amplitude threshold filtering
- Signal inversion
- Offset correction
- Statistical analysis
- Aerodynamic force plotting
- Experimental signal filtering
- Aerodynamic data visualization

# Experimental Context

The aerodynamic data-processing workflow was developed for a custom wind tunnel force-balance platform using multiple load cells, HX711 acquisition modules, and Python-based data logging.

The methodology supports aerodynamic validation, force monitoring, and experimental repeatability analysis.
