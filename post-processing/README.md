# CFD and Experimental Post-Processing

MATLAB scripts developed for aerodynamic signal filtering, CFD convergence evaluation, and experimental data analysis.

## Features

- Aerodynamic force signal processing
- Noise filtering and smoothing
- Residual convergence evaluation
- Coefficient convergence analysis
- Experimental data correlation

## Files

- `aero_signal_post_processing.m` — Experimental aerodynamic signal processing
- `aero_signal_post_processing_mesh.m` — CFD convergence and mesh-related post-processing
